# Dear ImGui Explorer

The demos of Dear ImGui, ImPlot and ImPlot3D, live in your browser, each beside its code, in C++ and Python, with the API at hand.

**Open it: https://pthom.github.io/imgui_explorer/**

![Dear ImGui Explorer](https://imgui-bundle.pages.dev/resources/og/imgui_explorer.jpg)

- A link opens a demo section, e.g. [ImPlot's line plots](https://pthom.github.io/imgui_explorer/?lib=implot&demo=Plots%2FLine%20Plots). Add `&lang=python` for the Python code.
- For AI assistants: [explorers.txt](https://imgui-bundle.pages.dev/llms/explorers.txt) lists every section, with its link.

This repository hosts the web build only. The explorer is part of [Dear ImGui Bundle](https://github.com/pthom/imgui_bundle), where its sources live ([external/imgui_explorer](https://github.com/pthom/imgui_bundle/tree/main/external/imgui_explorer)).
